# 野灣教育活動列表｜維護說明

網頁讀取 Google 試算表「公開用」分頁的資料，篩選後顯示成課程卡片。

## 資料夾內容

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體。日常維護只需要改 `<script>` 開頭的「設定區」 |
| `images/logo.png` | WildOne Logo |
| `images/og-image.png` | 分享到 LINE、Facebook 時出現的縮圖（1200×630） |
| `images/favicon.png` | 瀏覽器分頁小圖示 |
| `images/illust/` | 子銘的插圖，用在頁首、載入中、無結果，以及沒有封面圖的課程 |

## 試算表設定（只需設定一次）

1. 在原本的試算表新增一個分頁，命名為「公開用」。
2. 在「公開用」的 A1 貼上下列公式（`工作表1` 請換成原本資料分頁的名稱）：

   ```
   =QUERY('工作表1'!A:K,"select A,B,C,E,F,G,H,I,J,K where D='顯示'",1)
   ```

   只會帶出「顯示」的課程，「顯示與否」這一欄不會出現。
3. 「檔案 → 共用 → 發布到網路」：先取消原本的發布，再改為只發布「公開用」分頁，格式選「逗號分隔值 (.csv)」。
4. 把產生的網址貼到 `index.html` 設定區的 `CSV_URL`（目前已設定好）。

之後照舊在原本的分頁更新課程，「公開用」會自動同步，網頁約 5 分鐘內更新。

## 日常維護

- **新增或修改課程**：直接改原本的分頁。
- **新增封面圖**：把圖片放到 Google Drive，共用設定改成「知道連結的任何人」，再把分享連結貼到「活動封面圖」欄。沒填或讀不到的課程，會自動改用插圖。
- **新增分類**：在設定區的 `CATEGORY` 加一行，設定標籤顏色和插圖。
- **新增參與對象**：在設定區的 `TARGETS` 加一行，左邊的寫法要和試算表完全相同。

## 公開範圍提醒

GitHub Pages 上的所有檔案都是公開的，包括程式碼、圖片，以及「公開用」分頁的 CSV 內容（含封面圖的 Drive 連結）。請不要在「公開用」分頁放內部備註或聯絡資料。
